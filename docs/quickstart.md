# Quickstart

The repository currently contains the engineering foundation only. Runtime technology and application modules have not yet been selected.

## Clone

```bash
git clone https://github.com/lazylearnersudo/trade-engine.git
cd trade-engine
```

## Local private directories

Create these locally when needed. They are intentionally ignored by Git:

```bash
mkdir -p .docs prompts .pat
```

- `.docs/`: private working notes, research, and detailed design material.
- `prompts/`: private prompts used during development.
- `.pat/`: local access/bootstrap material and credentials.

Never commit secrets from these directories.
